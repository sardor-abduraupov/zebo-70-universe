# Зебо 70: Цифровая Вселенная

Создай с нуля очень впечатляющее интерактивное веб-приложение для 70-летия Зебо Мирзахакимовой (её можно называть «Зебо Мирзахакимова» или тепло «Зебо Буви», но НИКОГДА не используй общее слово «бабушка» как имя/обращение в интерфейсе). Проект должен ощущаться как большой премиальный цифровой experience, который мог бы быть разработан месяц, хотя его нужно завершить быстро. Это не обычная поздравительная страница, не фотоальбом и не слайдшоу.

Концепция: «ЗЕБО 70.0» — вымышленная персональная операционная система / цифровая вселенная Зебо Буви. Полностью на естественном русском языке. Очень крупная типографика, понятная человеку 70 лет, минимум мелкого текста, огромные кнопки, мягкие анимации, кинематографичный старт, ощущение премиального интерактивного продукта.

Сделай полноценный SPA с несколькими связанными мирами/разделами, но всё доступно с главного экрана:
1) Кинематографический boot sequence: чёрный экран, загрузка системы, «ЗЕБО 70.0», «Пользователь: Зебо Мирзахакимова», «Возраст: 70», «Статус: легендарный», затем плавный переход на dashboard.
2) Главный экран-десктоп: большие карточки/иконки «МОЙ МИР», «МОЯ СЕМЬЯ», «ИГРЫ», «ЗЕБО AI», «ТЕЛЕКАНАЛ ЗЕБО», «БУДУЩЕЕ», «ДОСТИЖЕНИЯ», «СЕКРЕТ». Сделай UI не как корпоративный dashboard, а как красиво арт-директированный digital exhibit.
3) «ЗЕБО AI»: фейковый умный помощник с готовыми кнопками-вопросами и красивыми ответами. Добавь юмор и тепло. Примеры: «Что делать, если я не голоден?» → «Система не обнаружила такую возможность. Рекомендуется поесть.»; «Кто главный человек в семье?» → «Выполняется анализ… Результат очевиден: Зебо Буви.» Сделай несколько сценариев и анимацию набора ответа.
4) «ИГРЫ»: несколько мини-игр, которые можно пройти прямо с экрана без ввода сложного текста: угадай, что выберет Зебо Буви; быстрый выбор между двумя вариантами; простая викторина; шкала «насколько хорошо ты знаешь Зебо». Показывай очки, крупные кнопки, забавные реакции и победный экран.
5) «ТЕЛЕКАНАЛ ЗЕБО»: имитация собственного телеканала с программами: «ЗЕБО НОВОСТИ», «ПОГОДА», «СПЕЦВЫПУСК», «РЕКЛАМА», «ШОУ». Всё можно переключать кнопками. Сделай телевизионную графику, ticker, logo, живые переходы.
6) «МОЯ СЕМЬЯ»: интерактивная визуальная «галактика» семьи. Пока без реальных данных — используй красиво оформленные demo-звёзды/узлы с понятной структурой и местами, куда позднее можно будет добавить имена. Центральный узел — «Зебо Мирзахакимова». Сделай это визуально впечатляющим и понятным.
7) «БУДУЩЕЕ»: выбор «80», «90», «100» и переход в футуристический интерфейс соответствующего года. Для 100 лет — очень красивый эмоциональный экран с текстом о будущем семьи, но не трагичный и не медицинский.
8) «ДОСТИЖЕНИЯ»: система наград/ачивментов с большой карточкой «70 лет», несколькими юмористическими достижениями и прогрессом.
9) «СЕКРЕТ»: сначала заблокирован. При открытии показать очень красивый финальный экран, который можно будет позднее наполнить личным текстом. Пока используй placeholder, но сделай структуру так, чтобы я легко заменил текст.

Обязательные качества: responsive для ноутбука и телевизора, управление мышью/кликом, без обязательного ввода текста; graceful fallback если нет звука; аккуратные hover/press эффекты; доступная контрастность; крупный readable русский шрифт; единая премиальная палитра (глубокий тёмный фон + тёплые золотистые/кремовые акценты, но без китча); не используй фотографии-заглушки из интернета. Создай реалистичную работу приложения сразу, не просто мокап: все экраны должны открываться, кнопки должны работать, переходы должны быть плавными. Подготовь несколько демо-контентов, чтобы приложение было интересно прямо после запуска.

Важно: не говори «бабушка» в интерфейсе. Используй «Зебо Мирзахакимова», «Зебо Буви», «Зебо 70.0».
